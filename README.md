# learnwith

This repo tracks and archives resources, tools and courses from the WAO [Learnwith site](https://web.archive.org/web/20251207115954/https://learnwith.weareopen.coop/). 
Learn more about We Are Open Co-op at [our website](https://web.archive.org/web/20260210121429/https://weareopen.coop/). This repo also has a wiki to explain how we created content for the Learn with WAO platform, made changes and technical background to some of the plugins that were used.
